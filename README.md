# AQI Extreme Predictor

A machine learning-based project that predicts extreme air pollution levels using air quality data.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- Extra Trees

## Features
- Air quality data analysis
- Data preprocessing
- AQI prediction
- Extreme pollution level prediction
- Machine learning model training

## Machine Learning Models
- Random Forest
- Extra Trees Classifier

## Purpose
The project helps analyze air quality data and predict high pollution conditions using machine learning.
